# CrispVoice 0.3.4

- Added a settings sidebar with search and six clear pages.
- Replaced long forms with compact rows, soft cards, and shorter descriptions.
- Added full-row expandable help for detailed settings information.
- Grouped recording, text delivery, sounds, and setup in General.
- Moved permission status and context controls to Privacy.
- Kept speech, local cleanup, cloud models, and provider keys in Models.
- Improved library and update settings without changing their behavior.

This update keeps saved settings, provider keys, downloaded models, and the existing app identifier and Developer ID certificate. It does not start a recording or change your cleanup source.

All six settings pages were checked on one Mac. Search, expanded help, and the library editor were checked. VoiceOver, another Mac, and Intel execution remain separate checks.
