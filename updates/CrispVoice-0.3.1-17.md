# CrispVoice 0.3.1

- Added automatic update checks and automatic downloads with Sparkle.
- Added Check for Updates to the app menu, menu bar, and Settings.
- Added controls to turn automatic checks and installation on or off.
- Updates wait for dictation, speech preparation, and setup to finish.
- Added signed update feeds and signed update archives.

Install this release once to enable future updates. Version 0.3.0 does not contain an updater. Automatic checks run about once an hour while the app is open. Automatic updates install when you quit. The same app identifier and Developer ID certificate are retained.
