# CrispVoice 0.3.2

- Added a smaller dictation chip with the target app's icon.
- Added a compact waveform and clear controls for Stop, Cancel, and Copy.
- Improved the processing, paste, and clipboard states.
- Added error and cancellation cards with clear actions.
- Retained the saved chip position and automatic fade.
- Retained Reduced Motion and Reduced Transparency support.

Record again starts a new recording after cancellation. The cancelled recording is discarded.

This update uses the same app identifier and Developer ID certificate. Your settings and provider key stay on your Mac. Sparkle can install this release from the signed update feed.
